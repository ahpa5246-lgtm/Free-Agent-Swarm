# Contributing

Issues, tests, accessibility fixes, translations and docs improvements are welcome. Keep all provider interactions opt-in and respect free-tier limits and platform terms.

Run `npm test` and `npm run build` before opening a pull request. Do not commit API keys, billing details, generated `dist/`, or code copied from incompatible licenses. Public demo functionality must remain fully usable without creating an account. Add regression tests for every state-machine change.
